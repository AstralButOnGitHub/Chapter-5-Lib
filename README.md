# Chapter5Lib
A Kristal library that adds a bunch of mechanics from Deltarune Chapter 5

## Features:

- Watering (Can, Flowers, Scissors, etc)
- Mushrooms and Netskies
- Falling Peaches/Rocks
- Cutable Vines
- Torii Gates (Dashing) ((***WIP***))
- Tall Grass
- Petal Mounds
- Sliding Terakotas
- Fusuma Walls/Doors
- Flowery Dollars and Pink Coins (Chests)
- Rabbit Plants

---

## Major Inconsistencies:

*If you can make any of these more accurate, please submit a PR!*

- Dashing is more like a recreation rather than a port, It'll get more accurate over time I swear!!
- Scissor search algorithm always spins right looking for the next flower, This plays similarly but can mess up timings in certain scenarios.
- Medium Watering Cans have water placement issues.
- Large Watering Cans are basically unusable.
- Netskie's animations are a little borked.
- Large Fusuma Doors don't have sounds or particles and can re-close.
